# Restaurant Manager — JavaFX
 
A desktop application built with **Java** and **JavaFX**, designed to manage a restaurant (menus, orders, tables, etc.).

## Tech stack
 
- **Java 17**
- **JavaFX** (`javafx-controls`, `javafx-fxml`) for the graphical interface

## Context
 
This project was built as part of an object-oriented Java programming course, featuring a JavaFX graphical interface.
